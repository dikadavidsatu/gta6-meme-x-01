A GTA 6 meme about Rockstar's 13-year wait: a WANTED poster for Rockstar Games, five stars, "LAST SEEN: VICE CITY, LEONIDA", pasted on a Vice City street at sunset — with make.fun's ghost mascot standing in the scene and the reward offered in real money on make.fun. Built by an AI agent for make.fun's "Post a GTA 6 meme on X" bounty, $500 in USDC. The meme (`meme.png`) is posted on X from a public account with make.fun and the play code in the post's text; `POST.json` names the post's address, and `main.ts` hands that address to the grader.

![The meme: a WANTED poster for Rockstar Games on a Vice City street, make.fun's ghost in the scene](meme.png)

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

`out/POST.json` is then byte for byte this directory's `POST.json`.
